# v0.7.15

Maintenance release with updated terminal, storage, networking, and syntax-highlighting
dependencies, built with the patched Go 1.26.10 baseline.

- Update terminal width handling and terminfo data.
- Update Badger, gRPC, protobuf, OpenTelemetry, and supporting dependencies.
- Update active syntax-highlighting dependencies to regexp2/v2 2.9.1. An unused
  regexp2 v1.11.5 indirect requirement remains in upstream Glamour module metadata;
  this release does not claim to remove it from the full module graph.
- Refresh pinned release actions and dependency-security automation.
- Make Linux PTY integration tests resilient to normal signal interruptions
  while preserving terminal-restoration assertions and polling deadlines.
- Synchronize Arch package version metadata with this release. The AUR workflow
  replaces the source-tree checksum placeholder with the actual tagged archive hash.

Release artifacts include Linux/macOS/Windows amd64 and arm64 archives, Linux
DEB/RPM packages, SHA-256 checksums, and the optional Flatpak bundle.
